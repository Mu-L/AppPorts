# AppPorts 후원하기

AppPorts는 완전 무료 오픈 소스 프로젝트이며 광고도 없고, 어떤 상업적 프로모션도 넣지 않습니다. 개인이 여가 시간에 유지 관리하는 프로젝트로 상업적 수익은 없습니다.

AppPorts 덕분에 로컬 저장 공간 수십 GB를 아꼈다면, 아래 QR 코드를 스캔해 개발자에게 커피 한 잔을 대접해 주세요. **금액은 자유이며, 작은 마음도 큰 힘이 됩니다.** 여러분의 후원이 프로젝트를 계속 이어 가는 힘입니다.

import SponsorList from "../.vitepress/theme/components/SponsorList.vue";

## 메시지 안내

후원할 때 메시지(비고)에 **닉네임**과 **링크**를 남겨 주세요. GitHub 프로필, 블로그, SNS 등 무엇이든 좋습니다.

보내 주신 「닉네임 + 링크」는 위 목록과 AppPorts의 「AppPorts 정보」 페이지에 표시됩니다.

::: tip 공개하고 싶지 않다면
닉네임이나 링크를 남기지 않으면 어떤 정보도 표시하지 않습니다.
:::

## 표시 순서

후원자는 다음 순서로 정렬됩니다.

| 우선순위 | 정렬 기준 |
| --- | --- |
| 1 | 후원 금액이 높은 순 |
| 2 | 금액이 같으면 후원 시각이 빠른 순 |

::: tip 금액에 제한은 없습니다
금액에는 하한이 없고, AppPorts의 모든 기능은 누구나 무료로 사용할 수 있습니다.
:::

AppPorts를 응원해 주시는 모든 분께 감사드립니다 ❤️
