## 留言說明

贊助時，請在留言（備註）中寫下你的**暱稱**和**個人連結**——GitHub 主頁、個人部落格、社群帳號等都可以。

收到贊助後，我們會把「暱稱 + 連結」收錄，並展示在上面的名單以及 AppPorts 的「關於 AppPorts」頁面中，感謝每一份支持。

::: tip 不想公開也沒關係
如果留言中未提供暱稱或連結，我們不會展示任何資訊。
:::

## 展示順序

贊助者按以下規則排序：

| 優先順序 | 排序規則 |
| --- | --- |
| 1 | 贊助金額從高到低 |
| 2 | 金額相同時，按贊助時間從早到晚 |

::: tip 金額不設門檻
贊助金額沒有下限，也不影響你使用 AppPorts 的任何功能——它始終對所有使用者完全免費。
